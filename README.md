# Tableau de bord interactif des KPI RH — Power BI

Projet de stage technique (DUT Ingénierie des données, EST El Kelâa des Sraghna – Université Cadi Ayyad, 2025-2026), réalisé chez **HR eXperts**.

## Objectif
Concevoir un système de reporting RH interactif et automatisé sous **Microsoft Power BI**, alimenté par les données du SIRH **HRAccess** (SQL Server).

## Contenu de la solution
- Plus de **30 KPI** répartis sur 6 domaines : effectifs, recrutement, turn-over, absentéisme, masse salariale, démographie RH
- Modèle de données en **étoile**
- Mesures **DAX** avancées
- Filtrage multi-axes (slicers dynamiques)
- Alertes visuelles **RAG** (Rouge / Orange / Vert)
- Dashboards thématiques : RH Global, Effectifs, Turn-over, Absentéisme, Masse salariale

## Technologies
Power BI Desktop · Power Query · DAX · SQL Server · HRAccess

## Utilisation
Ouvrir le fichier `.pbix` avec Power BI Desktop (Windows). La source de données d'origine (SQL Server HRAccess) n'est pas accessible publiquement ; les visuels s'appuient sur les données importées dans le fichier.
